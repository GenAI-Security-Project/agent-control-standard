If that describes you and you aren't listed here, open a PR that names the work.

## How attribution works here

A name goes on this list for work that ships. That means code or specification text merged to `main`, or a significant part in designing work that was. Comments, issue discussion, and reviews of other people's pull requests are welcome and they shape the standard, and on their own they don't add a name here.

We list contributors alphabetically by display name or handle, and we don't rank by commit count or seniority.

See [CONTRIBUTING.md](./CONTRIBUTING.md) for how to get involved.
